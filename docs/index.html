What it is

Modern radio spectrum is noisy, transient, and distributed across trunked talkgroups that hop frequencies every few seconds. BearSentinel (bcd325-dashboard) converts off-the-shelf scanner hardware — specifically the Uniden BCD325P2 and BCD996P2 — into an automated RF situational awareness appliance. Instead of sitting next to a squawking speaker, you get structured, queryable telemetry streamed straight into a browser or ingestion pipeline.

The dashboard connects over USB serial (115,200 baud ASCII), continuously interrogates the scanner's internal DSP registers, and decodes live transmissions across P25 Phase I & II, EDACS, Motorola Type II, and conventional FM channels. Talkgroup IDs (TGID), radio Unit IDs (UID), signal strength metrics, and GPS positions are categorized in real time.

How it works

The Uniden BCD325P2 exposes a comprehensive bidirectional serial control protocol. By issuing continuous non-blocking STS (Status) queries every 50–100 milliseconds, the dashboard monitors whatever channel the scanner's discriminator has locked onto. Command Polling Sequence

Communication follows a strict asynchronous lock-step request/reply contract. The host driver issues remote ASCII commands terminated by carriage returns (\r), and the scanner answers immediately before the next packet can be queued.

Quickstart

1. Connect the scanner: Connect your Uniden BCD325P2 or BCD996P2 to your desktop computer using a standard mini-USB cable. Ensure the scanner is powered on and set to 115,200 bps baud rate in Settings → Set C-Bps.

2. Launch Browser Console: Open the Web Serial Live Console in Google Chrome, Microsoft Edge, or Opera on desktop. Click Connect Scanner and pick the detected COM/serial port. Live transmission telemetry will begin streaming immediately.

3. Launch Full React UI: For full forensic analysis and historical SQLite persistence, run the standalone React application:

# Clone and install dependencies
git clone https://github.com/GlomarGadaffi/bcd325-dashboard.git
cd bcd325-dashboard
npm install

# Start local telemetry server
npm run dev

Remote Protocol Command Reference

The BCD325P2 serial protocol communicates over plain ASCII lines. The most critical commands utilized by the dashboard include:

CommandDirectionSyntax / ReturnDescription
MDLQueryMDL\r → MDL,BCD325P2\rRequests the hardware model identifier to verify receiver capabilities.
VERQueryVER\r → VER,1.06.00\rQueries scanner firmware version.
STSQuerySTS\r → STS,[status fields...]\rInterrogates live screen buffer: frequency, mode, RSSI, TGID, system name.
GLGQueryGLG\r → GLG,[lat],[lon],[alt]...\rReads attached GPS receiver coordinates (NMEA format).
VOLControlVOL,3\r → VOL,OK\rQueries or sets receiver audio volume level (0–15).
SQLControlSQL,2\r → SQL,OK\rQueries or adjusts RF squelch threshold (0–15).
KEYControlKEY,[code],[mode]\r → KEY,OK\rEmulates front-panel keypad presses (e.g., Hold, Scan, Avoid).
PRGStatePRG\r → PRG,OK\rEnters remote programming mode to modify channel banks in flash.
EPGStateEPG\r → EPG,OK\rExits programming mode and returns scanner to normal scanning operations.

The full specification covering all 80+ commands and response byte offsets is documented in the Complete Protocol Reference.
