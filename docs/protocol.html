bcd325·protocolspec ver 1.02

Serial control protocol reference, response schemas, and timing guidelines for the Uniden BCD325P2.

Physical & Link Layer Format

The scanner exposes an internal USB UART bridge via its front Mini-USB connector:

  • Baud Rate: 115,200 bps default (configurable: 4800 / 9600 / 19200 / 38400 / 57600 / 115200)
  • Data Framing: 8 Data Bits, 1 Stop Bit, No Parity (8-N-1)
  • Flow Control: None (Software pacing required; do not exceed command buffer)
  • Encoding: Plain 7-bit / 8-bit ASCII
  • Line Terminator: Carriage Return only (\r, ASCII 0x0D). The scanner never expects or sends Line Feed (\n).

Transaction Contract & Error Responses

The interface is strictly synchronous. The host must wait for a response line before transmitting the subsequent command. Overlapping commands trigger buffer collisions or frame dropouts.

Response CodeMeaningRecovery Strategy
OK\rCommand accepted and executed successfully.Proceed to next command.
ERR\rSyntax / Argument value error.Verify command parameters and value range.
NG\rCommand is currently invalid in the scanner's active state.e.g., Calling channel memory writes outside Program Mode (PRG).
FER\rFraming error detected on UART wire.Check baud rate configuration; reconnect serial port.
ORER\rOverrun error on receiver FIFO buffer.Increase host poll delay; do not exceed 20 QPS polling rate.

2. Telemetry Polling (The Real-Time Engine)

The engine continuously issues STS to query what the tuner and trunking decoder are receiving:

Controller → Radio:   STS\r
Radio → Controller:   STS,0,0,1,0,851.0125,0,0,NFM,0,0,0,FHP TROOP C,DISPATCH,2048,4102,5\r

STS Response Schema:

  1. Mode: 0 = Scan, 1 = Scan Hold, 2 = Search, 3 = Search Hold, 4 = Program Mode
  2. Squelch State: 0 = Closed (Quiet), 1 = Open (Receiving Carrier)
  3. Mute State: 0 = Audio Unmuted, 1 = Audio Muted
  4. Frequency: Active tuned center frequency (MHz, e.g. 851.0125)
  5. Modulation: AM, FM, NFM, WFM, FMB
  6. System Name: Text label for active trunked system (up to 16 chars)
  7. Department / Group Name: Text label for sub-group (up to 16 chars)
  8. Channel / Talkgroup Label: Active talkgroup name (up to 16 chars)
  9. TGID: Decimal Talkgroup Identifier (e.g. 2048)
  10. UID: Decimal Unit / Radio ID (e.g. 4102)
  11. RSSI: Received Signal Strength Indication (0 to 5 bars)

Recommended Polling Architecture

For lowest latency with zero FIFO overruns:

  • Issue STS once every 60 milliseconds (~16.6 Hz).
  • Maintain an exponential backoff if FER or ORER is received.
  • Issue GLG once every 5,000 milliseconds if mobile GPS tracking is active.
  • Close the serial port cleanly before rebooting or detaching hardware.
